# First-time setup for this repo

This repo does not include `test-data.js` — that's your actual test bank
and stays with you / gets generated by the test-bank repo's pipeline.

1. Copy your existing `test-data.js` into this folder (same one the
   original `index.html` was already loading).
2. Open `index.html` directly in a browser to run the app locally, or
   run `python3 assemble.py` to build `dist/index-live.html` — a single
   file you can paste into a claude.ai Create-mode chat to preview in
   the panel there.
3. `git init && git add . && git commit -m "platform: split into files"`
   once you've added test-data.js.

Once the extraction pipeline (test-bank repo) produces a schema-v1.1
JSON, drop its `tests` array into `test-data.js` here to see real
LaTeX/figure/token content render for the first time.
